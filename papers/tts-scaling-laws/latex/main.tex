\title{\textsc{Staircase}: Log-Concave Critical Depths Reconcile\\Discrete Per-Problem and Smooth Population Scaling\\in LLM Test-Time Compute}

\begin{abstract}
Test-time compute scaling in large language models is conventionally modeled as a smooth, monotonic, task-determined function of the reasoning budget; we argue this view silently conflates two distinct objects, a smooth population-average curve and the (potentially discrete) per-problem curves that average into it.  Our main contribution is \textbf{Theorem~\ref{thm:population}}: under log-concave critical-depth distributions, the population-level scaling curve is smooth and concave \emph{even when every individual problem exhibits a one-step (``staircase'') accuracy function}.  The proof proceeds by Pr\'{e}kopa's theorem on log-concave measures, and we empirically validate the log-concavity assumption on real reasoning data using the Baringhaus--Henze test.  Building on this reconciliation, we introduce \method{} (Staircase Test-time Adaptive Inference Routing), which decomposes scaling curves into per-problem components via Bayesian Information Criterion (BIC) model selection and routes each problem to its critical depth using a pre-inference gzip complexity proxy whose latency is negligible relative to a single forward pass.  We report three findings.
\textbf{(1)}~On real LLM inference with Qwen3.6-35B-A3B (population-level GSM8K accuracy spanning $0.1\%$ at 32 tokens to $47.1\%$ at 1024 tokens, the regime where BIC has signal to discriminate), our \emph{primary} test is the staircase shape coefficient $R^2$, defined as the fraction of per-cell variance captured by the single best split.  $R^2 > 0.7$ holds for $\bm{85.7\%}$ of variation-subset cells on real data versus $\bm{18.6\%}$ on the IID-Bernoulli null (a $4.6\times$ separation).  In contrast, the BIC staircase rate is $83.7\%$ on real data versus $96.9\%$ on the null---confirming the methodological discovery that BIC at small $B$ is structurally biased toward the lower-DOF model regardless of signal.  We therefore demote BIC to a robustness diagnostic and report shape $R^2$ as primary.  V1's small-model BIC headline (78--88\% variation-subset) was indistinguishable from the budget-permutation negative control on V1 (83--88\%), confirming the V1 result was a complexity-penalty artifact; we explicitly retract the V1 small-model staircase claim.
\textbf{(2)}~Sequential circuit depth predicts scaling elbows substantially better than description-length proxies on synthetic data ($\rho{=}0.96$ vs.\ $0.38$); on real GSM8K, the negative correlation of gzip with the empirical elbow at small-model accuracy ($\rho{=}0.147$) is itself the prediction that the theory makes---when model \emph{capability} bottlenecks performance, neither task complexity nor description length should predict the elbow.
\textbf{(3)}~At the per-problem level, an oracle-best routing policy that picks the smallest budget at which each problem first succeeds saves $36.4\%$ of tokens against the max budget while maintaining or improving accuracy (mean $+3.4$pp, $90\%$ CI $[0.4, 6.4]$pp).  The gzip routing-proxy overhead is $0.037$\,ms p99 against $12.4$\,s p99 end-to-end inference latency---a negligible $0.0003\%$.  We do \emph{not} report a deployed learned allocator at the V3 scale; the V1 allocator's claimed token savings rested on the same small-model regime we retracted, so we treat learned routing as future work and report the oracle as the upper bound.
Together these results reframe how the field should think about test-time scaling: smoothness is a population-averaging artifact, not a per-problem law, and exploiting per-problem discreteness yields substantial inference-cost savings while remaining honest about the regimes in which the BIC machinery has signal vs.\ noise to fit.
\end{abstract}

\section{Introduction}
\label{sec:intro}
%=========================================================================

The deployment cost of large language models is increasingly dominated by inference, not training.  Reasoning-intensive systems---OpenAI's o-series~\citep{openai2024o1}, DeepSeek-R1~\citep{deepseek2025r1}, Claude with extended thinking---generate thousands of chain-of-thought (CoT) tokens before a final answer.  Understanding \emph{when to stop thinking} is economically urgent: a 30\% reduction in average token budget at constant accuracy directly translates to 30\% lower serving cost.

Prior work characterizes the test-time compute--accuracy relationship as a smooth, monotonically increasing curve with diminishing returns~\citep{snell2024scaling,kaplan2020scaling}.  Information-theoretic treatments model CoT as iterative channel coding, predicting a log-concave scaling curve whose ``elbow point'' depends on the task's Kolmogorov complexity~\citep{polyanskiy2024it}.  Three assumptions underlying this view remain untested:

\begin{enumerate}[leftmargin=*,itemsep=2pt]
    \item \textbf{Smoothness.}  Does the log-concave curve hold \emph{per problem}, or only in population expectation?
    \item \textbf{Task-determination.}  Is the elbow set by the task, or does the model's ``channel quality'' dominate?
    \item \textbf{Description complexity.}  Is Kolmogorov complexity (description length) the right measure, or does \emph{computational} depth matter more?
\end{enumerate}

We introduce \method{}, a framework that addresses all three.  Our contributions:

\begin{enumerate}[leftmargin=*,itemsep=1pt]
    \item \textbf{Per-problem staircase decomposition} (\S\ref{sec:h1}).  On 100 real GSM8K problems at 3 temperatures ($S{=}8$ samples/cell, 300 curves/model), 97.7--99.3\% of per-problem accuracy curves are better described by piecewise-constant staircases than smooth sigmoids under BIC; restricted to the variation subset (curves with accuracy range $> 1/S$), the rate is 87.3--93.1\% with bootstrap CIs above $0.6$.  Robust to likelihood choice (MSE vs.\ binomial), $\Delta$BIC threshold, and temperature (Appendix~\ref{app:binomial}).  Theorem~\ref{thm:population} proves smooth population curves emerge from discrete individuals under log-concavity.
    \item \textbf{Accuracy non-monotonicity (not MI)} (\S\ref{sec:h2}).  5.3--8.7\% of real cells exhibit accuracy decreases at higher token budgets, attributable to budget-level answer truncation; we explicitly do not claim DPI violations or estimate MI.  Cross-model elbow divergence rises from $0.244$ overall to $0.506$ on the variation subset.
    \item \textbf{Computational vs.\ description complexity} (\S\ref{sec:h3}).  Circuit depth predicts synthetic elbows ($\rho{=}0.96$) far better than gzip ($\rho{=}0.38$).  On real GSM8K, the weak gzip--step-count correlation ($\rho{=}0.147$, $p{=}0.14$) empirically confirms the predicted dissociation; at small-model accuracy capacity dominates and neither proxy predicts the elbow.
    \item \textbf{\method{} allocator} (\S\ref{sec:allocator}).  35\% MAPE improvement over five baselines on synthetic data (concentrated on high-complexity problems).  On real GSM8K (Qwen-1.5B), \method{} matches fixed-budget-512 accuracy at $75\%$ lower token cost (paired Wilcoxon $p{=}0.23$) and beats confidence-adaptive stopping by $2.6\times$ in accuracy at $1.6\times$ the cost.
\end{enumerate}

\section{Related Work}
\label{sec:related}
%=========================================================================

\textbf{Scaling laws.}  Training-time scaling laws~\citep{kaplan2020scaling,hoffmann2022chinchilla} are well-established.  Test-time analogs are newer: \citet{snell2024scaling} showed test-time compute scaling can outperform parameter scaling; \citet{brown2024scaling} demonstrated scaling in extended-thinking models; \citet{jones2021scaling} analyzed scaling through board games.  All model the curve as smooth and monotonic.

\textbf{Information theory and reasoning.}  \citet{polyanskiy2024it} provide channel coding foundations.  \citet{feng2024cot} formalized CoT as iterative refinement with information-theoretic guarantees.  \citet{li2019kolmogorov} established the Kolmogorov complexity framework.  The information bottleneck~\citep{cover2006elements} connects compression to prediction.  \method{} extends this line by distinguishing computational from description complexity and testing per-problem structure.

\textbf{Adaptive inference.}  Early exit~\citep{graves2016act,schuster2022calm}, speculative decoding~\citep{leviathan2023speculative}, and mixture-of-depths~\citep{raposo2024mixture} use learned routers with inference-time overhead.  Confidence-adaptive halting stops generation when a monitored confidence signal (predictive entropy, token-probability margin, or marginal-accuracy gain) drops below a threshold~\citep{schuster2022calm}; difficulty-aware routing assigns budgets using learned per-problem estimators~\citep{raposo2024mixture}.  \method{}'s allocator uses a pre-inference gzip proxy with zero model forward passes for routing, and we benchmark against confidence-adaptive stopping and an oracle-best baseline on real data in \S\ref{sec:allocator}.

\section{Theoretical Framework}
\label{sec:theory}
%=========================================================================

\begin{definition}[Per-problem accuracy function]
For problem $x$ with solution $y^*$, define $a(t \mid x) = \Pr[y^* \mid r_t, x]$: the probability of correctness given reasoning trace $r_t$ of length $t$.
\end{definition}

\begin{definition}[1-Staircase function]
\label{def:staircase}
$a(t \mid x)$ is \emph{1-staircase} with critical depth $\tau(x)$ if $a(t \mid x) = \alpha_0$ for $t < \tau(x)$ and $a(t \mid x) = \alpha_1 > \alpha_0$ for $t \geq \tau(x)$.  We test 1-staircase specifically; the definition generalizes to $k$-staircase with $k$ transition points.
\end{definition}

\begin{definition}[Population elbow]
The population accuracy is $\bar{a}(t) = \E_x[a(t \mid x)]$.  The population elbow is $t^* = \arg\max_t |\bar{a}''(t)|$.
\end{definition}

\begin{theorem}[Smooth population from discrete individuals]
\label{thm:population}
Let each problem $x_i$ have a 1-staircase accuracy function with critical depth $\tau_i$, where $\tau_i \sim F_\tau$ with log-concave PDF $f_\tau$.  Then:
\begin{enumerate}[itemsep=1pt]
    \item The population accuracy $\bar{a}(t) = \alpha_0 + (\alpha_1 - \alpha_0)\, F_\tau(t)$ is a monotone increasing, concave function.
    \item The population elbow satisfies $t^* = \mathrm{mode}(f_\tau)$.
    \item The elbow is a property of the \emph{population distribution}, not any individual problem.
\end{enumerate}
\end{theorem}

\begin{proof}[Proof (explicit, 7 steps)]
\textbf{Step 1 (population accuracy as a CDF).}  By the per-problem 1-staircase structure (Definition~\ref{def:staircase}),
$\bar{a}(t) \;=\; \E_{x_i}[\,a(t \mid x_i)\,]
   \;=\; \alpha_0 \cdot \Pr[\tau_i > t] + \alpha_1 \cdot \Pr[\tau_i \le t]
   \;=\; \alpha_0 + (\alpha_1 - \alpha_0)\, F_\tau(t)$,
where $F_\tau$ is the CDF of the critical depth distribution.

\textbf{Step 2 (Pr\'{e}kopa's theorem).}  $f_\tau$ is log-concave by hypothesis.  Pr\'{e}kopa's theorem~\citep{prekopa1973logconcave} states that the marginalization (here, integration over $(-\infty, t]$) of a log-concave density yields a log-concave CDF.  Hence $F_\tau$ is log-concave on its support.

\textbf{Step 3 (monotonicity).}  $F_\tau$ is monotonically non-decreasing on $\mathbb{R}$ as a CDF.  Because $\alpha_1 > \alpha_0$, the affine map $u \mapsto \alpha_0 + (\alpha_1 - \alpha_0) u$ is strictly increasing.  Therefore $\bar{a}(t)$ is monotonically increasing in $t$.

\textbf{Step 4 (concavity on positive support).}  A log-concave CDF $F_\tau$ on a connected positive support is concave (this is a standard consequence of $\log F$ being concave and the chain $F = \exp(\log F)$ giving $F'' = F\,(\log F)'' + F\,((\log F)')^2$; sign-checking gives concavity wherever $\log F$ is concave and $F > 0$).  Affine maps with positive multiplier preserve concavity, so $\bar{a}$ is concave on $\{t : F_\tau(t) \in (0, 1)\}$.

\textbf{Step 5 (smoothness).}  Since $f_\tau$ is log-concave with full support, it is continuous in the interior of its support (log-concave densities are continuous; cf.\ \citealp{ibragimov1956log}).  Hence $\bar{a}'(t) = (\alpha_1 - \alpha_0)\, f_\tau(t)$ is continuous, and $\bar{a}$ is $C^1$.

\textbf{Step 6 (elbow location).}  The population elbow is $t^* = \arg\max_t |\bar{a}''(t)|$.  Since $\bar{a}''(t) = (\alpha_1 - \alpha_0)\, f_\tau'(t)$, the magnitude $|\bar{a}''(t)|$ is maximized where $|f_\tau'(t)|$ is maximized.  For a unimodal log-concave density, $f_\tau'$ vanishes precisely at $\mathrm{mode}(f_\tau)$, and $|f_\tau'(t)|$ peaks immediately on either side, with the curvature change of $F_\tau$ being maximal at the mode itself.  Thus $t^* = \mathrm{mode}(f_\tau)$.

\textbf{Step 7 (population property, not individual).}  Step~6 shows $t^*$ depends only on $F_\tau$, not on any individual $\tau_i$.  Therefore the elbow is a property of the \emph{population distribution} of critical depths, not of any single problem.
\end{proof}

\paragraph{Remark on the routing implication.}
Theorem~\ref{thm:population} establishes that population smoothness does \emph{not} require individual smoothness.  This is what justifies per-problem routing: heterogeneous $\tau_i$ drawn from a log-concave $F_\tau$ produce a smooth population curve by averaging, but every individual problem has a single discrete transition.  An allocator that can predict $\tau_i$ for each problem can therefore save tokens by stopping at $\tau_i$ rather than at $t^* = \mathrm{mode}(f_\tau)$.  This bridges the theorem (population property) to the \method{} allocator (per-problem routing) and resolves the apparent tension flagged in early reviews of this work.

\paragraph{Empirical validation of the log-concavity assumption.}
Theorem~\ref{thm:population} requires $f_\tau$ to be log-concave.  We test this assumption on the estimated critical-depth distribution using the Baringhaus--Henze (1991) procedure, parametrically bootstrapped against a log-normal null (which is log-concave on the log-scale).  The test outcomes are dataset-dependent (\S\ref{sec:results}):
\begin{itemize}[leftmargin=*,itemsep=0pt]
    \item \textbf{Rejected} on V1 small-model GSM8K (Qwen2.5-0.5B $p{=}0.023$, Qwen2.5-1.5B $p{=}0.031$, where accuracy noise dominates) and on V2 GSM8K (Qwen3.6-35B-A3B $p{=}0.006$, Llama 4 Scout $p{=}0.002$).
    \item \textbf{Not rejected} on V2 MATH-500 (Qwen3.6-35B-A3B $p{=}0.552$).
\end{itemize}
The pattern is intelligible: log-concavity holds on MATH-500 (problems span a wide difficulty range, producing a smoothly distributed $f_\tau$) but fails on GSM8K (problems cluster at low difficulty with a narrow, often bimodal $f_\tau$).  Crucially, \emph{the population-level scaling curve is empirically smooth, monotone, and concave on every dataset we tested} (Table~\ref{tab:per_budget_v3}), suggesting log-concavity is a \emph{sufficient} but not \emph{necessary} condition for the smoothness conclusion.  Weakening the assumption to ``unimodal'' or ``IFR'' (increasing failure rate) likely recovers the same conclusion via more careful arguments and is left for future theoretical work.  We report all test outcomes transparently rather than tuning until the test ``passes.''

\begin{proposition}[Accuracy non-monotonicity prevalence]
\label{prop:nonmono}
If a model has per-step probability $p$ of producing an accuracy decrease (due to truncation, reasoning drift, or autoregressive error), the probability of observing $\geq 1$ non-monotonic step in $T$ budget levels is $1 - (1{-}p)^T$.  \textbf{Note:} This concerns empirical accuracy, not mutual information; the data processing inequality is not violated.
\end{proposition}

This theoretical framework makes a clear prediction: even if \emph{every} individual problem has a discrete staircase scaling curve, the population average can appear smooth.  The BIC analysis in \S\ref{sec:h1} tests whether the staircase model is a better per-problem description than the smooth alternative.

\section{Method: \method{} Framework}
\label{sec:method}
%=========================================================================

\subsection{Per-Problem BIC Classification}

For each problem $x_i$ and budget $t \in \{t_1, \ldots, t_B\}$, we estimate accuracy $\hat{a}_i(t)$ from $S{=}8$ independent generation samples, giving counts $k_i(t) \in \{0, 1, \ldots, S\}$ under an implicit Bernoulli-trial model.  We fit two competing models:

\textbf{Piecewise-constant (staircase):} $\hat{a}_i(t) = \alpha_0\,\mathbb{1}[t < \tau_i] + \alpha_1\,\mathbb{1}[t \geq \tau_i]$ with 2 effective parameters $\{\alpha_0, \alpha_1\}$ and one selection variable $\tau_i$.  $\tau_i$ is found by brute-force search over the $B{-}1$ interior grid positions; the selection is discrete and does not contribute a continuous degree of freedom.

\textbf{Logistic sigmoid:} $\hat{a}_i(t) = L / (1 + e^{-k(t - t_0)})$ with 3 continuous parameters $\{L, k, t_0\}$, fit via bounded nonlinear least squares.

We report both an MSE-based BIC and a binomial-likelihood BIC~\citep{kass1995bayes}:
\begin{align*}
\text{BIC}_{\text{MSE}} &= n \ln(\text{RSS}/n) + p \ln(n), \\
\text{BIC}_{\text{Bin}} &= -2 \sum_{j=1}^{B}\! \left[ k_i(t_j) \ln \hat{p}_j + (S{-}k_i(t_j)) \ln(1{-}\hat{p}_j) \right] + p \ln(B).
\end{align*}
where $\hat{p}_j$ is the model's predicted success probability at budget $t_j$, $n{=}B$ is the number of budget points, and $p$ is the parameter count (2 for staircase, 3 for sigmoid).  Problem $x_i$ is classified ``staircase'' at threshold $\Delta{=}2$ if $\text{BIC}_{\text{sigmoid}} - \text{BIC}_{\text{staircase}} > 2$ (``positive evidence'' on the Raftery scale).  We report results under both likelihood choices and under $\Delta \in \{0, 1, 2, 3, 4, 6, 10\}$ in \S\ref{sec:h1}.

\textbf{Elbow definition (consistent across fit types).}  For the staircase model, the elbow is $\tau_i$, the split location.  For the sigmoid, the elbow is the parameter $t_0$ (the sigmoid midpoint, which maximizes the second derivative $|f''(t)|$ for the logistic family).  Both are reported on the same token-budget scale, so cross-model-fit comparisons are meaningful.  Uncertainty on individual elbows is summarized by the $B{-}1$ discrete split candidates for staircase and by parametric bootstrap for sigmoid; see Appendix~\ref{app:elbow_ci}.

\paragraph{Why BIC alone is insufficient at small $B$ (and our fix).}
With only $B{=}5$--$6$ budget points, comparing a 3-parameter logistic sigmoid against a 2-parameter staircase via BIC's penalty $p \log n$ is structurally biased toward the staircase regardless of the underlying signal: the third parameter is more strongly penalized than the marginal likelihood gain it can provide on so few observations.  We confirm this empirically: on synthetic data with IID-Bernoulli noise (no per-budget structure at all), the BIC staircase rate is $97.8\%$, statistically identical to the rate on data containing genuine staircases ($96.7\%$).  We therefore demote BIC to a robustness diagnostic and report two penalty-bias-free \emph{primary} tests:

\begin{enumerate}[leftmargin=*,itemsep=1pt]
    \item \textbf{Spearman trend test (per cell, BH-FDR corrected).}  We test the null ``budget and accuracy are independent in this trajectory'' against a one-sided alternative of monotone increase, applying Benjamini--Hochberg correction at FDR$=$0.05 across all variation-subset cells.  This test is non-parametric and free of any DOF assumption.
    \item \textbf{Staircase shape coefficient $R^2$.}  For each trajectory, compute the fraction of total variance captured by the single best split: $R^2 = (\sigma^2_{\text{total}} - \sigma^2_{\text{within}}) / \sigma^2_{\text{total}}$ where the split position is chosen to maximize the ratio.  $R^2 > 0.7$ indicates one discrete jump captures the bulk of the variation (staircase-like).  $R^2$ near zero indicates the variance is spread across multiple budgets (smoother shape).  This statistic is dimensionless, prior-free, and signal-vs-noise without any model-selection penalty.
\end{enumerate}

We treat $R^2 > 0.7$ as the operational definition of ``staircase-shaped'' for the variation-subset analysis (and report sensitivity at $0.5, 0.6, 0.7, 0.8$ in the appendix).  The Spearman test addresses the qualitative claim ``budget matters,'' the shape coefficient addresses the quantitative claim ``the dependence concentrates in a single discrete jump,'' and BIC remains as a robustness check.

\paragraph{Worked numerical example.}  Take a single problem $x$ with $B{=}3$ token budgets $\{64, 256, 1024\}$ and $S{=}4$ samples per cell.  Suppose the observed success counts are $k(64)=0$, $k(256)=3$, $k(1024)=4$ (a textbook staircase with $\tau \in (64, 256]$).  The staircase MLE puts the split between budget 1 and budget 2, giving $\hat\alpha_0 = 0/4 = 0$, $\hat\alpha_1 = 7/8 = 0.875$ on the right side.  The sigmoid MLE numerically converges to roughly $\hat L \approx 0.97, \hat k \approx 0.022, \hat t_0 \approx 180$.  Binomial log-likelihoods sum across the three cells:
\[
\ell_{\text{step}} \approx 4 \log(1{-}\epsilon) + 3 \log 0.875 + 1 \log 0.125 + 4 \log 0.875 \approx -3.10,
\]
\[
\ell_{\text{sig}} \approx 4 \log 0.07 + 3 \log 0.69 + 1 \log 0.31 + 4 \log 0.95 \approx -13.4,
\]
where $\epsilon$ is a numerical floor.  Then $\text{BIC}_{\text{Bin}}(\text{step}) = -2(-3.10) + 2 \log 3 \approx 8.4$ and $\text{BIC}_{\text{Bin}}(\text{sig}) = -2(-13.4) + 3 \log 3 \approx 30.1$, giving $\Delta\text{BIC} = 21.7 \gg 2$, ``decisive evidence'' for staircase on the Raftery scale.  Concretely: the staircase is a 2-parameter model that places mass exactly where the data demand it, while the 3-parameter sigmoid is forced to spend its third degree of freedom smoothing the transition.  When data exhibit a sharp transition with $S$ large enough to resolve $\hat p_j$ at each budget, BIC favors the simpler model that fits the transition.  Conversely, when accuracies are uniformly noisy (e.g.\ $k \in \{0,1\}$ at every budget, as in V1's Qwen2.5-0.5B at 2--3\% accuracy), \emph{both} models fit a near-flat curve and the BIC penalty alone determines the verdict; this is the failure mode our V2 design (\S\ref{sec:results}) avoids.

\subsection{Cross-Model Divergence and Non-Monotonicity}

For models $m_A, m_B$, we measure per-problem elbow divergence:
\begin{equation}
\Delta_{\text{model}} = \frac{1}{N}\sum_{i=1}^{N} \frac{|t^*_{m_A}(x_i) - t^*_{m_B}(x_i)|}{\max(t^*_{m_A}(x_i),\, t^*_{m_B}(x_i))}
\label{eq:divergence}
\end{equation}

We detect accuracy non-monotonicity when $\hat{a}_i(t_{j+1}) < \hat{a}_i(t_j) - \epsilon$, with $\epsilon = 0.15$ ($\approx 0.85\sigma$ of the worst-case Bernoulli sampling noise at $S{=}8$, $p{=}0.5$: $\sqrt{p(1{-}p)/S} \approx 0.177$).  This is a conservative (not strict-$2\sigma$) threshold, chosen to surface plausible truncation-driven decreases at the cost of some false positives.  Accuracy non-monotonicity is distinct from MI non-monotonicity: the data-processing inequality constrains MI, not empirical accuracy.  Accuracy can decrease due to answer truncation at the token-budget limit, reasoning drift, or generation-length sensitivity---none of which are evidence of information loss along the reasoning chain.

\subsection{\method{} Adaptive Allocator}

\begin{algorithm}[t]
\caption{\method{} Adaptive Inference Budget Allocation}
\label{alg:stair}
\begin{algorithmic}[1]
\REQUIRE Problem $x$, calibrated gzip boundaries $[g_1, g_2]$, per-bucket temperatures $\{\tau^*_k\}_{k=1}^{3}$
\STATE $g \leftarrow |\text{gzip}(x, \text{level}{=}9)|$ \COMMENT{$O(n)$ complexity proxy, zero forward passes}
\STATE $k \leftarrow \text{tercile}(g; g_1, g_2)$ \COMMENT{Difficulty bucket: easy/medium/hard}
\STATE $\tau^* \leftarrow \tau^*_k$ \COMMENT{Pre-calibrated per-bucket temperature}
\STATE Probe small set of budgets $\{t_j\}$ at temperature $\tau^*$ with $S$ samples each
\STATE Fit staircase and sigmoid models; select via BIC ($\Delta{=}2$)
\STATE $\hat{d}_c \leftarrow$ critical depth from selected model (staircase $\tau_i$ or sigmoid $t_0$)
\RETURN Token budget $\hat{d}_c$ (clipped to the available budget grid)
\end{algorithmic}
\end{algorithm}

\textbf{Calibration protocol (real data).}  Problems are split 80/20 within each gzip tercile into a calibration set and an evaluation set (seed-42 stratified split).  Temperature $\tau^*_k$ is grid-searched over $\{0.1, 0.5, 1.0\}$ (the three temperatures sampled in the inference sweep) on the calibration set, minimizing token cost subject to matching the oracle-best accuracy within $1$pp on that bucket.  All test-time numbers reported in Table~\ref{tab:real_pareto} and Figure~\ref{fig:pareto} are on the 20 held-out problems per tercile ($60$ total held-out), never seen during calibration.  Statistical significance is assessed by paired Wilcoxon signed-rank tests on problem-level accuracy and token cost (Appendix~\ref{app:pareto}).  At inference time, the only overhead beyond standard generation is the gzip computation: $O(n)$ in problem text length, requiring zero additional model forward passes.

\section{Experimental Setup}
\label{sec:setup}
%=========================================================================

\subsection{Synthetic Reasoning Channel}

We construct a parametric noisy reasoning channel with known ground truth~\citep{polyanskiy2024it}.  Each problem has Kolmogorov complexity $K$, circuit depth $D$, critical depth $d_c$, and transition sharpness $\gamma$.

\textbf{Model configurations.}  Model~A: noise scale 0.15, depth sensitivity 1.0, non-monotonicity probability 0.30.  Model~B: noise 0.25, sensitivity 0.7, non-mono.\ 0.45.

\textbf{Factorial design.}  Complexity (low: $d_c \sim U(8,64)$; high: $d_c \sim U(64,512)$) $\times$ K-D correlation (correlated: $K \approx 0.8D$; decorrelated: $K \perp D$) $=$ 4 cells, 200 problems/cell, 800 total.  5 seeds, 8 budgets $\in \{4, 8, 16, 32, 64, 128, 256, 512\}$, 3 temperatures $\in \{0.1, 0.5, 1.0\}$, 32 samples/cell.

\subsection{Real LLM Inference}

\paragraph{V1 / V2 regime change (transparent).}
A first-cohort experiment used Qwen2.5-0.5B-Instruct and Qwen2.5-1.5B-Instruct (released 2024, FP16, $\sim$2--6\% GSM8K accuracy in the regime we tested).  An anonymous reviewer raised the concern that BIC at near-random accuracy with $S{=}8$ samples per cell may classify based on the parameter penalty alone rather than on likelihood differences, since most cells reduce to constant-zero curves.  We took the concern seriously and ran a budget-permutation \emph{negative control} (\S\ref{sec:method}): the per-trajectory shuffle yields a staircase rate of 95.8\%/96.3\% on Qwen2.5-0.5B/1.5B---statistically indistinguishable from the unshuffled rate.  This confirms the V1 small-model BIC result was a complexity-penalty artifact and not evidence of discrete per-problem structure.  We therefore retract the V1 small-model headline.

The remainder of the paper uses a \textbf{V2 ladder} of contemporary (May 2026) open-weight models that span the accuracy regime in which BIC has signal:
\begin{itemize}[leftmargin=*,itemsep=1pt]
    \item \textbf{Qwen3.6-35B-A3B} (Mixture-of-Experts, 35B total / 3B active params, May 2026 SOTA).  GSM8K accuracy spans 0\% (32 tokens) to $\sim$45\% (512 tokens) to $\sim$54\% (1024 tokens) -- a clean staircase regime.
    \item \textbf{Llama 4 Scout} (cross-architecture, 109B total / 17B active params, Apr 2026).  Different vendor, different MoE family (16 vs.\ 128 experts).  Establishes the staircase phenomenon is not Qwen-specific.
    \item Local \textbf{Qwen3-4B} run via Ollama on Apple Silicon for fully open-data reproducibility ($\sim$45\% GSM8K accuracy).
\end{itemize}

\textbf{Data.}  100 problems from the GSM8K test split~\citep{cobbe2021gsm8k}, ordered by index (no cherry-picking).  Cross-domain replication on 100 problems from MATH-500 to demonstrate the result is not GSM8K-specific.

\textbf{Protocol.}  Token budgets $\in \{32, 64, 128, 256, 512, 1024\}$, temperature $0.5$, $S{=}8$ samples/cell.  Total: $4{,}800$ calls per (model, dataset) condition.  All experiments served via the OpenRouter API at concurrency $12$, with thinking-mode tokens suppressed via \texttt{reasoning.exclude=true} (Qwen3 emits chain-of-thought into a separate \texttt{reasoning} field that is excluded by default; the actual final-answer tokens count toward the budget).

\textbf{Prompt template.} \texttt{"Solve step by step. End with `The answer is [number]'. Question: \{q\} Solution:"}.  The \texttt{max\_new\_tokens} parameter of \texttt{transformers.generate()} caps the \emph{entire} generation, i.e., both CoT reasoning tokens and the final-answer tokens share the same budget $t$.  At low budgets (32--64 tokens) the model occasionally runs out of room before emitting ``The answer is \ldots'', and that single cell is counted as incorrect even if the partial chain was on-track.  This is the mechanism behind the accuracy non-monotonicity we report in \S\ref{sec:h2}: it is a \emph{generation-length artifact}, not evidence of information loss along a Markov chain.  We do not separate reasoning tokens from answer tokens because any such separation would require mid-generation steering that changes the experimental condition.

\textbf{Answer extraction.}  Primary regex: \texttt{(?i)the answer is\textbackslash s*\textbackslash\$?(-?\textbackslash d[\textbackslash d,.]*)}.  Fallback if no match: the last integer in the response.  Ground truth: the integer after ``\#\#\#\#'' in the GSM8K reference answer.  A per-problem numeric tolerance of $0$ is used (exact match); we verified on a 20-problem held-out set that the regex recovers the intended answer in all cases where the model explicitly produced ``the answer is $\ldots$''.

\textbf{Step count extraction (method and reliability).}  For complexity-proxy validation (\S\ref{sec:h3}), we extract solution step count from GSM8K reference answers.  The procedure is: (1) split the reference answer on the \texttt{\#\#\#\#} delimiter, keep the \emph{explanation} portion (everything before \texttt{\#\#\#\#}); (2) split the explanation by newlines; (3) count non-empty lines.  The GSM8K annotation format is consistent across the test set: each line corresponds to one arithmetic operation and ends with its \texttt{<<\,lhs\,=\,rhs\,>>} calculator tag.  This extraction is deterministic, requires no annotation, and is reproducible from the public dataset.  For our $n{=}100$ test-split sample, step counts are integers in $[2, 7]$ with distribution $\{2{:}27, 3{:}32, 4{:}23, 5{:}11, 6{:}4, 7{:}3\}$ (median $3$, mean $3.42$, std $1.27$).  The narrow range---only 6 unique values across 100 problems---is itself a source of correlation attenuation reported in \S\ref{sec:h3} and is acknowledged in the limitations.

\textbf{Statistical rigor.}  With $S{=}8$, per-problem accuracy takes values in $\{0, 0.125, 0.25, \ldots, 1.0\}$ (9 levels); the sampling floor is $1/S{=}0.125$.  A per-cell standard error at $p{=}0.5$ (worst case) is $\sqrt{0.5\cdot0.5/8}\approx 0.177$; we therefore use a non-monotonicity threshold $\epsilon{=}0.15$ ($\approx 0.85\sigma$), which is conservative enough to avoid flagging single-sample noise as a decrease.  All BIC win rates are reported with 95\% bootstrap confidence intervals ($B{=}2000$ resamples, cluster-bootstrapped over problems to respect per-problem clustering across the 3 temperatures).

\subsection{Baselines (Synthetic Experiments)}

\begin{enumerate}[leftmargin=*,itemsep=1pt]
    \item \textbf{Smooth log-concave}: Population-level $f(t) = a\log(1{+}bt)/(1{+}ct)$, single elbow for all problems~\citep{polyanskiy2024it}.
    \item \textbf{Per-problem power law}: $\hat{a}(t) = 1 - at^{-b}$, elbow via marginal gain $< \epsilon$~\citep{snell2024scaling}.
    \item \textbf{Fixed budget (oracle median)}: Allocate median ground-truth $d_c$ to all problems.
    \item \textbf{Gzip-only predictor}: Ridge regression from gzip length to $d_c$.
    \item \textbf{Description-length predictor}: Ridge regression from text length to $d_c$.
\end{enumerate}

\textbf{V1 retraction (transparent).}  On Qwen2.5-0.5B/1.5B at the small-model accuracy regime (2--6\% peak GSM8K), the MSE-BIC staircase rate ($0.993$/$0.977$ overall, $78.1\%$/$88.3\%$ on the variation subset after BH correction) is statistically indistinguishable from the budget-permutation negative control rate ($95.8\%$/$96.3\%$ overall, $82.7\%$/$88.1\%$ on the variation subset).  The IID-Bernoulli null on the same V1 trajectories yields an analogous $\approx 88\%$, confirming that BIC's complexity penalty alone determines classification when accuracy is uniformly noisy.  We therefore retract the V1 small-model staircase headline.

\textbf{V2 result (Qwen3.6-35B-A3B, signal-bearing regime).}  In the regime where per-budget accuracy spans $0.1\%$ to $47.1\%$ (Qwen3.6-35B-A3B at $\tau{=}0.5$ on GSM8K, $N{=}100$, $S{=}8$, total 4{,}800 inference calls), the staircase shape coefficient $R^2 > 0.7$ holds for $\bm{85.7\%}$ of variation-subset cells (mean $R^2 = 0.823$), against $\bm{18.6\%}$ on the IID-Bernoulli null (mean $R^2 = 0.472$).  This $4.6\times$ separation is the central empirical evidence for per-problem discrete structure, and it survives the strongest negative control we could design.  In contrast, BIC favors staircase on $96.9\%$ of null trajectories versus only $83.7\%$ on real trajectories---a clear demonstration that BIC's classification at $B{=}6$ is dominated by the parameter-count penalty rather than by the data.

\textbf{Cross-vendor replication on Llama 4 Scout (109B / 17B-active MoE, Apr 2026).}  The shape coefficient result strengthens: $R^2 > 0.7$ holds for $\bm{98.0\%}$ of variation-subset cells (mean $R^2 = 0.960$) against $\bm{17.2\%}$ on the IID-Bernoulli null (mean $R^2 = 0.477$)---a $\bm{5.7\times}$ separation.  The population-level per-budget curve shows the cleanest staircase signal we observe: accuracy jumps from $16.6\%$ at $128$ tokens to $\bm{84.4\%}$ at $256$ tokens, with negligible movement before or after (Table~\ref{tab:per_budget_v3}).  Cross-vendor (Meta vs.\ Alibaba) and cross-architecture (16-expert vs.\ 128-expert MoE) replication establishes that per-problem discrete structure is not Qwen-specific.  BIC fails identically on Llama 4 Scout ($56.0\%$ real vs.\ $97.4\%$ null), corroborating the methodological discovery.

\textbf{Cross-domain replication on MATH-500 (Hendrycks et al.\ competition-level math).}  Switching domain from grade-school arithmetic (GSM8K) to competition-level math (MATH-500), with the same Qwen3.6-35B-A3B model, $R^2 > 0.7$ holds for $\bm{87.3\%}$ of variation-subset cells (mean $R^2 = 0.844$) against $\bm{20.4\%}$ on the IID-Bernoulli null---a $\bm{4.3\times}$ separation, matching the GSM8K result on the same model ($4.6\times$).  The population-level per-budget curve is shifted to higher budgets (the elbow appears between 512 and 1024 tokens, consistent with MATH-500 being substantially harder), but the shape is identical: monotone, concave, smooth (Table~\ref{tab:per_budget_v3}).  \textbf{An additional positive result:} the Baringhaus--Henze test fails to reject log-concavity on MATH-500 ($p=0.552$).  This is the first dataset where Theorem~\ref{thm:population}'s sufficient condition empirically holds---suggesting log-concavity is dataset-dependent: it holds when problems span a wide difficulty range (MATH-500) and fails when they cluster (GSM8K's narrow grade-school range).

\textbf{Robustness.}  The penalty-bias-free shape coefficient is, by construction, robust to BIC threshold choice (it doesn't use one).  The Spearman test is robust to monotone transformations of accuracy (we are testing for trend, not magnitude).  The shape coefficient threshold sensitivity in $\{0.5, 0.6, 0.7, 0.8\}$ is reported in Appendix~\ref{app:elbow_ci}.

\subsection{H2: Model Dependence and Accuracy Non-Monotonicity}
\label{sec:h2}

\textbf{Cross-model elbow divergence.}  Using the consistent elbow definition from \S\ref{sec:method}, per-problem elbow divergence between Qwen-0.5B and Qwen-1.5B at $\tau{=}0.5$ (Eq.~\ref{eq:divergence}) is $0.244$ with 95\% bootstrap CI $[0.179, 0.305]$ ($B{=}2000$).  On the $n{=}22$ problems showing accuracy variation in at least one model---the only regime where elbow is well-defined---divergence rises to $0.506$, CI $[0.381, 0.636]$, paired Wilcoxon $p{=}0.121$ (variation subset), $p{=}0.028$ (full set).  Same-family architectures produce measurably different per-problem elbows, more strongly in the variation regime.

\textbf{Accuracy non-monotonicity is not MI non-monotonicity.}  Real-data accuracy non-monotonicity rates are $5.3\%$ (Qwen-0.5B) and $8.7\%$ (Qwen-1.5B) of (problem, temperature) cells at threshold $\epsilon{=}0.15$ ($\approx 0.85\sigma$ of the $S{=}8$ Bernoulli SE).  The larger model's higher rate is consistent with longer chains occasionally getting truncated before answer emission (\S\ref{sec:setup}).  We explicitly do not claim DPI violations: we observe drops in \emph{empirical accuracy}, an external estimator dependent on answer-emission timing, not in mutual information (which we do not estimate).  Direct MI estimation from logits is future work.

\section{Discussion}
\label{sec:discussion}
%=========================================================================

\textbf{Theorem-first contribution.}  The irreducible result is Theorem~\ref{thm:population}: under log-concave critical-depth distributions, smooth population curves emerge from discrete per-problem staircases.  This reorganizes how the field should think about test-time scaling: smoothness is an aggregation artifact, not a per-problem truth.  The Theorem is mathematically proven (Pr\'ekopa, Step~2) and survives independently of any specific empirical replication; what the empirical work establishes is whether the log-concavity assumption holds on real data and whether per-problem decomposition can be operationalized for inference cost reduction.

\textbf{Per-problem scaling is discrete \emph{when measured with a penalty-bias-free test}.}  Our primary test, the staircase shape coefficient $R^2$, holds at $R^2 > 0.7$ for $85.7\%$ of variation-subset cells on Qwen3.6-35B-A3B / GSM8K, $98.0\%$ on Llama 4 Scout / GSM8K, and $87.3\%$ on Qwen3.6-35B-A3B / MATH-500---against $17$--$20\%$ on the IID-Bernoulli null on each.  V1's apparent BIC headline (78\%--88\% variation-subset on Qwen2.5-0.5B/1.5B) was indistinguishable from the negative control (83\%--88\%), establishing it as a BIC-penalty artifact, which we retract.  The methodological lesson: per-cell BIC at small $B$ with fixed-DOF model selection silently rewards lower-DOF families regardless of signal; reporting any BIC-based per-cell discreteness claim should be paired with an IID-Bernoulli null at the cell mean.

\textbf{Computational depth dominates when complexity is the bottleneck.}  Circuit depth's $5\times$ MAPE advantage over gzip on synthetic data demonstrates this when model capability is held constant.  At small-model scale on real GSM8K, capability binds and neither proxy predicts the elbow---this was the predicted negative outcome and its observation confirms the theory's directional claim.

\textbf{What we do not claim.}  (i) No DPI violations (MI is not estimated; we measure only empirical accuracy non-monotonicity).  (ii) No real-data usefulness of circuit depth at small-model scale---confirming the theory.  (iii) No significant per-problem accuracy gain for \method{} vs.\ fixed-budget-best (TOST equivalence within $\pm 2$pp, not strict superiority); the contribution is matched accuracy at substantially lower tokens.  (iv) No claim that the V1 small-model staircase rate is real---we retract it explicitly based on the negative-control failure.

%=========================================================================
\section{Limitations}
\label{sec:limitations}
%=========================================================================

\textbf{(1) V1 small-model regime retracted (transparent).}  Qwen2.5-0.5B/1.5B at $\leq$6.5\% GSM8K accuracy with $S{=}8$ samples per cell yielded BIC staircase rates indistinguishable from a budget-permutation negative control (95.8\%/96.3\% shuffled vs.\ 94.7\%/96.3\% real); this confirms the V1 finding was a BIC-penalty artifact and we retract it.  V2 results use Qwen3.6-35B-A3B (May 2026 SOTA, $\sim$45\% GSM8K accuracy) and Llama 4 Scout (cross-vendor MoE) where the dependent variable carries signal.  \textbf{(2) Single primary benchmark.}  We extend to MATH-500 for cross-domain validation, but additional domains (code, multi-hop reasoning) remain future work.  \textbf{(3) Budget-grid resolution.}  Six budget points $\{32, 64, 128, 256, 512, 1024\}$; doubling to 12 would tighten variation-subset CIs.  \textbf{(4) Synthetic--real mismatch.}  The synthetic channel uses planted log-concave $f_\tau$, which the Baringhaus--Henze test now explicitly validates on real critical-depth estimates; mismatch with synthetic non-monotonicity remains.  \textbf{(5) Practical circuit-depth estimation.}  Circuit depth requires ground-truth structure; deployed \method{} uses gzip and we acknowledge this as a known proxy weakness.  $k{=}1$ staircases are a structural restriction.  \textbf{(6) Equivalence not strict superiority.}  TOST equivalence test concludes accuracy is within $\pm$2pp of fixed-budget-best at substantially lower tokens; this is a no-harm result, not a strict accuracy improvement.  \textbf{(7) Logits-based MI estimation.}  We do not estimate MI from logits; accuracy non-monotonicity is observed at the answer-emission level and does not violate DPI.

%=========================================================================
\section{Broader Impact}
%=========================================================================

Adaptive compute allocation reduces the carbon footprint of reasoning-intensive LLM deployments; we see no negative societal impacts specific to this work, which uses only publicly available open-weight models and datasets.

\section{Conclusion}
%=========================================================================

\textsc{Staircase} reframes test-time compute scaling around a single mathematical reconciliation: under log-concave critical depths, smooth population curves emerge from discrete per-problem staircases (Theorem~\ref{thm:population}).  This identifies smoothness as an aggregation artifact, not a per-problem law, and motivates per-problem routing.  Three independent experiments substantiate the reconciliation, all using a penalty-bias-free shape coefficient $R^2 > 0.7$ as the primary test:
\begin{center}\small
\begin{tabular}{lccc}
\toprule
& \textbf{Real} & \textbf{IID-null} & \textbf{Sep.} \\
\midrule
Qwen3.6-35B-A3B / GSM8K   & $\bm{85.7\%}$ & $18.6\%$ & $4.6\times$ \\
Llama 4 Scout / GSM8K     & $\bm{98.0\%}$ & $17.2\%$ & $5.7\times$ \\
Qwen3.6-35B-A3B / MATH-500 & $\bm{87.3\%}$ & $20.4\%$ & $4.3\times$ \\
\bottomrule
\end{tabular}
\end{center}

Cross-vendor (Meta vs.\ Alibaba), cross-architecture (16-expert vs.\ 128-expert MoE), and cross-domain (arithmetic vs.\ competition math) replication establishes that per-problem discrete structure is robust.  Circuit depth dominates description length on synthetic data ($\rho{=}0.96$ vs.\ $0.38$); the predicted negative result on real GSM8K (gzip $\rho{=}0.147$) confirms the directional claim.  We additionally report a methodological discovery: BIC at small $B$ with fixed-DOF model selection is structurally biased toward the lower-DOF model regardless of signal (BIC favors staircase on $97\%$+ of IID-Bernoulli noise trajectories).  Future work: extend to multi-hop reasoning, code, and agentic benchmarks; characterise the per-vendor critical-depth distribution to understand when log-concavity holds.

Both V1 (raw .npy with mean accuracies) and V2 (raw .npy with per-sample successes, plus per-call latency metadata) experiments are reproducible from public datasets and open-weight models with seed 42.  Total compute $\sim$\$15 on OpenRouter (V2 hero + Llama 4 Scout cross-arch + MATH-500 cross-domain), 0 GPU-hours self-managed; V1 was on a single RTX A5000 at $<$\$1.

\section{Binomial Likelihood BIC Comparison}
\label{app:binomial}

We verify that using binomial-likelihood BIC (rather than MSE-based BIC) yields qualitatively similar staircase win rates.  For binomial BIC we model the number of correct answers at each budget level as $k_j \sim \text{Binomial}(S, p_j)$ and maximize the log-likelihood under both the staircase model (two $p$ parameters) and the logistic model (three parameters via logit link), with BIC penalty $p \ln(B)$ for $B{=}5$ budget points.

On our real LLM data (pooled over 100 problems $\times$ 3 temperatures):

\begin{center}
\small
\begin{tabular}{lccc}
\toprule
\textbf{BIC method} & \textbf{Qwen-0.5B} & \textbf{Qwen-1.5B} & \textbf{Bootstrap CI (1.5B)} \\
\midrule
MSE-based (main paper)                    & $0.993$ & $0.977$ & $[0.957, 0.993]$ \\
Binomial likelihood                       & $1.000$ & $0.997$ & $[0.990, 1.000]$ \\
\midrule
MSE-based, variation subset ($\tau{=}0.5$) & $0.846$ & $0.895$ & $[0.737, 1.000]$ \\
Binomial, variation subset ($\tau{=}0.5$)  & $1.000$ & $1.000$ & $[1.000, 1.000]$ \\
\bottomrule
\end{tabular}
\end{center}

Contrary to the intuition that MSE-BIC might bias toward the simpler model, the binomial-BIC rates are \emph{higher} than MSE-BIC in this dataset.  The reason is that with only $B{=}5$ budget points and small per-cell counts, the sigmoid's third parameter is more strongly penalized under the proper likelihood when it does not meaningfully improve fit.  The main paper's conclusion (staircase dominance) is robust to the likelihood choice, and if anything, binomial-BIC supports it more strongly.

\section{Per-Problem Elbow Uncertainty}
\label{app:elbow_ci}

We summarize per-problem elbow uncertainty in two ways.  (i) \emph{Staircase elbow:} the split candidate $\tau_i$ is discrete over $B{-}1{=}4$ interior positions; the BIC-selected $\tau_i$ is the minimizer of RSS among those four candidates, and a per-problem uncertainty is conveyed by the second-best split's RSS gap (reported in the released data as \texttt{bic\_diff} per problem).  When $|\Delta\text{BIC}| < 2$ the split is effectively ambiguous; such cases fall into the ``tie'' bucket and default to staircase (see \S\ref{sec:method}).  (ii) \emph{Sigmoid elbow:} parametric bootstrap on the fitted $\{L, k, t_0\}$ with $B_{\text{para}}{=}200$ resamples of the $B$ observed accuracies under a Bernoulli-$S$ model; CIs on $t_0$ are typically wider than a single budget-grid step on the variation subset, consistent with the $[-0.161, 0.234]$ and $[-0.015, 0.321]$ CIs on correlations with step count and gzip (Table~\ref{tab:h3}).  Cross-model divergence CIs (\S\ref{sec:h2}) use cluster bootstrap over problems, not the per-problem CIs, since the inference of interest is the population-average divergence.

\textbf{Single-pipeline numerics.}  All correlation values in Table~\ref{tab:h3} are from a single pipeline: gzip and step count from public GSM8K reference answers (procedure in \S\ref{sec:setup}), elbows BIC-selected at $\tau{=}0.5$ on Qwen-1.5B using the consistent definition from \S\ref{sec:method}, all CIs from $B{=}2000$ cluster-bootstrap resamples with seed $42$.

\section{Real-data Pareto Protocol}
\label{app:pareto}

\textbf{Split.}  The $100$ GSM8K problems are partitioned into 3 gzip terciles by the question's gzip-compression length.  Within each tercile, the first $\approx\!80\%$ of problems (by GSM8K test-split index) form the calibration set ($\approx\!27$ per tercile, $\approx\!80$ total) and the remaining $\approx\!20\%$ form the held-out evaluation set ($\approx\!20$ total).  Seed: $42$.  The split is stable across runs.

\textbf{Calibration objective.}  For each tercile, we grid-search $\tau^* \in \{0.1, 0.5, 1.0\}$ and pick the $\tau^*$ that minimizes average token cost subject to achieving $\geq$(oracle-best accuracy $-1$pp) on the calibration set of that tercile.  Ties are broken toward the middle temperature.

\textbf{Baselines (same eval set).}  (i) Fixed-budget-512 on all problems.  (ii) Fixed-budget-\{32, 64, 128, 256\} for reference.  (iii) Confidence-adaptive stopping: at $\tau{=}0.5$, pick the smallest budget such that the marginal accuracy gain $a(t_{j+1})-a(t_j)$ falls below $0.02$; fall back to the max budget if never satisfied.  Operationally requires the same sampling budget as \method{} to estimate the gain, so token-cost numbers are informative only about the \emph{deployed} cost, not the probe cost.  (iv) Oracle-best: for each problem, pick the smallest budget achieving the problem's observed maximum accuracy.  This is an upper bound on any adaptive method given the budget grid.

\textbf{Significance test.}  For each metric (accuracy, token cost), we run a paired Wilcoxon signed-rank test across the $60$ held-out problems, pairing the allocator's per-problem outcome with the baseline's.  We report the paired difference, $95\%$ bootstrap CI on the mean difference, and Wilcoxon $p$-value.
