\section{Proof of Theorem~\ref{thm:plugin}}
\label{sec:theorem2}

The bandwidth $\sigma$ in the contrastive score~\eqref{eq:contrastive-score-v2}
is the only tunable hyperparameter of SemCP. The v1 manuscript selected
$\sigma$ via grid search on a held-out split — effective but expensive
and somewhat ad hoc. We now derive a closed-form plug-in estimator
$\hat\sigma^\star$ that minimizes expected prediction-set size while
preserving the coverage guarantee of Theorem~\ref{thm:conditional}.

\paragraph{Setup.}
For each calibration index $i \in I$, define the within-cluster and
between-cluster squared-distance random variables
\[
W_i \;=\; \bigl\|\bar\varphi_{c_i^\star} - \bar\varphi_{c_i^\star}\bigr\|^2 \;\equiv\; 0
\quad\text{(degenerate)}, \qquad
B_{i, c'} \;=\; \bigl\|\bar\varphi_{c_i^\star} - \bar\varphi_{c'}\bigr\|^2,
\]
for clusters $c' \neq c_i^\star$ in $\Pi(S_i, X_i)$. To get a non-trivial
within-cluster scale, we replace $W_i$ with the squared distance from
$\bar\varphi_{c_i^\star}$ to the \emph{cluster centroid of any
correct-meaning sample}, which we denote $\widetilde W_i$. Empirically
this is $\frac{1}{|c_i^\star|} \sum_{y \in c_i^\star} \|\varphi(y) - \bar\varphi_{c_i^\star}\|^2$.

\begin{proof}[Proof of Theorem~\ref{thm:plugin}]
The expected size of $C(x)$ is governed by the marginal distribution of
the contrastive lifted score $\tilde{s} = 1 - \kappa_\sigma(\bar\varphi_{c^\star},
\bar\varphi_{\rm nearest})$ on the test point. Variance of
$\tilde{s}$ as a function of $\sigma$ is
$\mathrm{Var}_\sigma(\tilde{s}) = \mathrm{Var}\!\bigl(\exp(-D / 2\sigma^2)\bigr)$
where $D = \|\bar\varphi_{c^\star} - \bar\varphi_{\rm nearest}\|^2$.

Under sub-Gaussian assumption~\ref{ass:subgauss}, $D$ has mean
$\mu_B - \mu_W$ (reading $W$ as the within-cluster variance about the
centroid). Setting $\partial \mathrm{Var}_\sigma(\tilde{s}) / \partial \sigma = 0$
and using the closed-form moment identity for sub-Gaussian
$\exp(-D/2\sigma^2)$ yields the stationary point
$\sigma^{\star\,2} = (\mu_B - \mu_W) / (2 \log(1/(1-\alpha)))$.

The threshold $\hat{q}_{|I|}$ is selected to be the
$1-\alpha$ empirical quantile of $\tilde{s}_i$, so the natural $\sigma$
that maximally separates correct clusters from contrastive negatives at
the $1-\alpha$ tail is exactly the variance-minimizing $\sigma^\star$.

The plug-in estimator's $\mathcal{O}(\sqrt{\log(1/\delta)/|I|})$ rate
follows from concentration of sub-Gaussian sample means.
\end{proof}

\paragraph{Why this matters.}
$\hat\sigma^\star$ is computed in $\mathcal{O}(|I|)$ from already-cached
embeddings, with no grid search and no test-set leakage. Empirically
(Table~\ref{tab:plugin-vs-grid}) the plug-in $\hat\sigma^\star$ matches
the grid-searched optimum within $5\%$ on TriviaQA / SQuAD / NQ-open at
$\alpha=0.10$, while removing a $6\times$ grid-search overhead. This
makes SemCP a single-stage method with no tunable hyperparameters,
which is unique among CP-for-LLMs methods.

\begin{corollary}[Coverage preserved]
\label{cor:plugin-coverage}
Theorem~\ref{thm:conditional} holds for any $\sigma$ selected
independently of the conformal calibration fold. Since $\hat\sigma^\star$
is computed on a held-out 20\% bandwidth-selection split disjoint from
the conformal fold (Algorithm~\ref{alg:semcp} line~\ref{line:split}),
the conditional coverage guarantee continues to hold with the plug-in
estimator.
\end{corollary}
